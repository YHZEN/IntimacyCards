# IntimacyCards
IntimacyCards 是一款面向18 + 成年情侣的纯本地单机互动 APP，采用暗夜烛影视觉风格，安卓、iOS 双平台适配。 应用以抽卡玩法为核心，划分 4 个互动等级，梯度把控互动尺度，搭配 R/SR/SSR/UR 多档稀有卡牌与炫酷翻牌、粒子光效，仪式感十足。内置十连保底、抽卡去重、10 种趣味功能卡等机制，还提供石头剪刀布、骰子、翻硬币等双人对战玩法。 配套情侣主页、收集图鉴、互动日记，可记录相处日常与甜蜜回忆。全程数据本地加密存储，配备多级密码、舒适度过滤与安全词机制，隐私性拉满。后续还支持自制卡牌、加密数据备份，适合情侣居家休闲互动，增添相处趣味。
